VinylVibes API is the backend service for an online vinyl record store. It provides endpoints for user authentication, catalog browsing via Discogs, album enrichment from Last.fm and YouTube, shopping cart checkout, and admin management — all built with Node.js, Express, Prisma, and Redis.

## What the API does

VinylVibes API integrates three external services to deliver a rich vinyl shopping experience:

- **Discogs** — search the world's largest music database for records, browse by genre, and get detailed release information including tracklists, labels, and community popularity stats.
- **Last.fm** — fetch album biographies and find similar artists to power personalized recommendations.
- **YouTube** — look up music videos for any album in the catalog.

Prices are calculated entirely server-side using the release year and Discogs community popularity (want/have ratio) — clients never supply or influence pricing.

## Get started in 3 steps

<Steps>
  <Step title="Create an account">
    Register with a username and password via `POST /registro`. No email verification required.
  </Step>
  <Step title="Get your token">
    Log in via `POST /login` and receive a JWT token valid for 7 days. Include it in every protected request as `Authorization: Bearer <token>`.
  </Step>
  <Step title="Browse and buy">
    Search the Discogs catalog, add items to your cart, and place an order via `POST /checkout`. The API calculates prices server-side.
  </Step>
</Steps>

<Note>
  The server requires several environment variables to start — `JWT_SECRET`, `DATABASE_URL`, `REDIS_URL`, and API keys for Discogs, Last.fm, and YouTube. See the [architecture overview](/concepts/architecture) for the full list.
</Note>
